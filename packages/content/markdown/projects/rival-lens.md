RivalLens is a Chrome extension that turns the current competitor webpage into a structured competitive brief. It extracts key information from SaaS landing pages, pricing pages, and marketing sites, then helps you compare positioning and messaging quickly.

The project also includes an Astro marketing site built with a strict Swiss-style design system, Playwright screenshot automation, and a manual Chrome Web Store release flow.
